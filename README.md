## 🎯 Syllabus Mapping & Assignment Breakdown

### Assignment 01: Responsive Homepage Design
- **Objective:** Create a mobile-first responsive layout for a Hospital/Healthcare portal.
- **Key Features:** Bootstrap 5 grid, sticky navigation bar, emergency hotline strip, doctor consultation booking modal, patient testimonials, and accessibility semantics.
- **URL:** [https://wtl-assignment-01-homepage.onrender.com/](https://wtl-assignment-01-homepage.onrender.com/)

### Assignment 02: Dynamic To-Do List Application
- **Objective:** Manage dynamic client-side tasks with event listeners and DOM manipulation.
- **Key Features:** Priority badges (High, Medium, Low), category tagging, due date pickers, in-place modal editing, live keyword search, completion percentage bar, and persistent storage via `localStorage`.
- **URL:** [https://wtl-assignment-02-todolist.onrender.com/](https://wtl-assignment-02-todolist.onrender.com/)

### Assignment 03: Public API Data Fetching using Async/Await
- **Objective:** Asynchronously consume public RESTful endpoints and update the DOM.
- **Key Features:** Uses native `fetch` with `async/await` and `try...catch...finally`. Features dynamic loading skeleton, error boundary with retry trigger, rating/price sorting, and product inspection modal.
- **URL:** [https://wtl-assignment-03-fetch-api.onrender.com/](https://wtl-assignment-03-fetch-api.onrender.com/)

### Assignment 04: Client-Side Interactive Web App in TypeScript
- **Objective:** Develop a strongly-typed web application using custom interfaces and strict types.
- **Key Features:** Academic SGPA / GPA calculator built with typed interfaces (`Course`, `GradeLetter`, `AcademicSummary`), credit-weighted grade points computation, interactive course table, and pre-compiled ES6 distribution.
- **URL:** [https://wtl-assignment-04-typescript.onrender.com/](https://wtl-assignment-04-typescript.onrender.com/)

### Assignment 05: React Functional Components, Props & `useState`
- **Objective:** Build a component hierarchy using JSX, passing props down and managing reactive state.
- **Key Features:** SkillUp Academy course catalog featuring functional components (`Header`, `CourseCard`, `EnrolledDrawer`), prop drilling of data and callbacks, and dynamic state synchronization with `useState`.
- **URL:** [https://wtl-assignment-05-react-props.onrender.com/](https://wtl-assignment-05-react-props.onrender.com/)

### Assignment 06: React API Integration with Axios & State Boundaries
- **Objective:** Use the Axios HTTP client with component lifecycle management and visual state feedback.
- **Key Features:** Fetches user profiles from REST API, displays animated shimmer placeholder skeletons during loading, profile inspection modal, and an interactive **"Simulate 404 Error"** viva testing button.
- **URL:** [https://wtl-assignment-06-react-axios1.onrender.com/](https://wtl-assignment-06-react-axios1.onrender.com/)

### Assignment 07: User Registration Form with Controlled Components
- **Objective:** Implement two-way data binding with React state and custom regular expressions.
- **Key Features:** Real-time email validation using regex, password strength indicator (Weak, Fair, Good, Strong), password visibility toggler, instant field validation on blur, and verified submission preview card.
- **URL:** [https://wtl-assignment-07-react-form.onrender.com/](https://wtl-assignment-07-react-form.onrender.com/)

### Assignment 08: Student Management CRUD with PHP & MySQL
- **Objective:** Execute Create, Read, Update, and Delete operations using PHP Data Objects (PDO).
- **Key Features:** Prepared statements protecting against SQL Injection, department & keyword search filters, `database.sql` seed script, and automated SQLite cloud fallback for zero-configuration Docker hosting on Render.
- **URL:** [https://wtl-assignment-08-php-crud.onrender.com/](https://wtl-assignment-08-php-crud.onrender.com/)

### Assignment 09: Express.js RESTful API Backend Server
- **Objective:** Architect a RESTful API server serving static files, JSON metadata, and full student CRUD.
- **Key Features:** Express middleware pipeline (`cors`, `express.json`, `express.static`), status code semantics (`200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found`), web testing dashboard, and importable Postman collection.
- **URL:** [https://wtl-assignment-09-express-api.onrender.com/](https://wtl-assignment-09-express-api.onrender.com/)

### Assignment 10: MongoDB Mongoose CRUD & Serverless Summary Function
- **Objective:** Connect Express to MongoDB Atlas and implement a serverless analytical function.
- **Key Features:** Mongoose ODM schema with strict validators, live connection to MongoDB Atlas, web portal dashboard, and a serverless lambda function (`api/summary.js`) calculating institutional metrics and top performers.
- **URL:** [https://wtl-assignment-10-mongodb.onrender.com/](https://wtl-assignment-10-mongodb.onrender.com/)

### Assignment 11: Server-Side Authentication with JWT & Protected Routes
- **Objective:** Implement stateless authentication using JWT, Bcrypt password hashing, and Role-Based Access Control.
- **Key Features:** User registration with salted Bcrypt password hashing, JWT signing, `protect` Bearer token authentication middleware, role-restricted routes (`student`, `faculty`, `admin`), and interactive browser testing console.
- **URL:** [https://wtl-assignment-11-jwt-auth.onrender.com/](https://wtl-assignment-11-jwt-auth.onrender.com/)
